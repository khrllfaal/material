# Hasil QA & Perbaikan (Okt 2026)

Diuji pada data contoh: 30 proyek, 15 bahan, ±350 Bahan Masuk, ±530 Pemakaian.

## Lulus
- Login benar/salah, kunci akun setelah 5 gagal; tanpa login → 401.
- Owner: semua tulis (proyek, bahan, transaksi, user, RAP, tambah-bahan) → 403; tombol tulis tidak tampil di 11 menu.
- Admin Lapangan: hanya proyek yang ditugaskan; tidak bisa ubah/hapus transaksi lama, master, user, RAP.
- Simpan Bahan Masuk/Pemakaian, desimal `0,322`, tambah bahan baru, antrean offline lalu terkirim otomatis.
- Excel/PDF dari Dashboard, Monitor Stok, Analisis RAP, Riwayat; filter kartu status; pencarian; paging.
- Kecepatan API (30 proyek): 5–35 ms per endpoint; 100 input paralel 0,4 detik; balapan ID sama tidak error 500.

## Ditemukan & diperbaiki
- Jumlah negatif/nol, tanggal ngawur atau di masa depan, dan bahan tak dikenal diterima / membuat error 500 → kini ditolak dengan pesan jelas (422).
- Menghapus Master Bahan/Proyek diam-diam menghapus seluruh transaksinya (cascade) → kini ditolak (409) bila sudah punya transaksi.
- Admin Lapangan bisa melihat daftar semua proyek → kini hanya proyeknya.
- Header keamanan (nosniff, frame DENY, CSP, Referrer-Policy, HSTS bila HTTPS) di API dan frontend (`frontend/.htaccess` + meta CSP).
- Tabel 180–1000 baris dirender sekaligus → kini 50 baris/halaman, header tabel menempel.
- Ikon pencarian tertutup kolom input; tanggal/Aksi terpotong dua baris; Riwayat mobile berupa tabel sempit → kini daftar kartu per tanggal.
- Font kecil (11–12 px) dinaikkan, angka tabular, fokus keyboard terlihat, input mobile 16 px (tidak zoom di iPhone).

## Belum / saran (dibanding sistem perusahaan besar)
- Belum ada layar Audit Log (data sudah tercatat di tabel `audit_log`).
- Belum ada pembatasan percobaan login per IP / CSRF token (cookie SameSite=Lax sudah menahan sebagian besar).
- Pemakaian belum wajib terikat pekerjaan; belum ada persetujuan (approval) transaksi.
- Uji beban sungguhan perlu di server Apache/PHP-FPM; uji lokal memakai server PHP satu-thread.
- Backup: jadwalkan `backend/api/bin/backup_db.php` lewat cron hosting.
- Tidak ada uji otomatis di repo (saat ini uji manual/skrip).
